# summarization-s-
this is a summarization tool that helps you get the brief from pdfs, html sites or catch up on your morning news too. trying to add the url and image version too(two alternate versions because sometimes one works and the other doesn't)

important outsources you'll require are:
⦿ langchain (you can get from here: https://pypi.org/project/langchain/)
⦿ ollama (you can get from here: https://docs.ollama.com/)
⦿ requests-html (just from your preferred terminal)
⦿ bs4 and beuatifulsoup 
⦿ a new virtual environment thru venv
⦿ maybe pypdf too
⦿ and the lovely github to assist you on the way
